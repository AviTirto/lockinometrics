# BMW Motivation Images

Drop your BMW images here!

## Supported filenames:
- bmw1.jpg / bmw1.png / bmw1.jpeg
- bmw2.jpg / bmw2.png / bmw2.jpeg
- bmw3.jpg / bmw3.png / bmw3.jpeg
- bmw4.jpg / bmw4.png / bmw4.jpeg
- bmw5.jpg / bmw5.png / bmw5.jpeg

## Instructions:
1. Save your BMW images with any of the names above
2. The app will randomly select one when you click "Get Motivated!"
3. Add as many as you want (up to 5 different images)

Example:
```
public/motivation-images/
  ├── bmw1.jpg
  ├── bmw2.png
  └── bmw3.jpeg
```
